## 網頁簡介
此網頁核心目標在於呈現課程中的各項技術實作，並透過互動式介面展示個人虛擬角色的成長過程。

*   **互動特色：** 響應式設計、動態分數計算、作業分頁切換效果。


## 虛擬角色介紹：Eve Mactans
**「歡迎來到伊芙的家，想要來一杯能看見美妙夢境的調酒嗎？」**

## 課程作業實作紀錄

### 作業 I：Vtuber 初探與 Live2D
*   **內容：** 學習 Vtuber 的基本構成，包含人設設計與直播環境準備。
*   **技術：** 使用 Copilot 生成插圖、OBS 直播至 YouTube、影片字幕製作。
*   **心得：** 體會到幕後準備的繁雜，包含配音、表情控制與介面切換。

### 作業 II：故事詠唱與影像化
*   **內容：** 透過 AI 工具將人設故事轉化為視覺圖像，並進行故事敘述直播。
*   **技術：** Copilot 提示詞優化、影片剪輯、YouTube 直播。
*   **心得：** 挑戰如何透過精準的詠唱詞繞過 AI 的過度審查，產出符合暗黑風格的角色圖。

### 作業 III：虛擬去背與場景融合
*   **內容：** 使用 Animaze 進行面部捕捉，並學習如何處理虛擬背景。
*   **技術：** Animaze 軟體應用、OBS 濾鏡（去除顏色）、CC0 素材應用。
*   **心得：** 克服了綠幕去背時與角色瞳孔顏色重疊的技術難題。

### 作業 IV：3D 模型捏臉實作
*   **內容：** 自行捏製 3D 虛擬角色模型，將 Eve 從 2D 轉化為 3D。
*   **技術：** VRoid Studio 建模、素材修改與套用。
*   **心得：** 體會到 3D 建模中細節（如髮型、材質）對角色還原度的重要性。

### 作業 V：Unity 互動與直播功能
*   **內容：** 將 3D 模型匯入 Unity，並實作直播互動功能。
*   **技術：** Unity Asset Store 應用、Donate 粒子效果、動作選單、演唱歌曲《酔いどれ知らず》。
*   **心得：** 透過 Unity 實現更豐富的角色互動，讓 Eve 具備動態演出的能力。

### 作業 VI：舞台搭設與分鏡設計
*   **內容：** 在 Unity 中搭建完整的演出場景與分鏡。
*   **技術：** Unity Timeline、VRM/FBX 匯入、分鏡設計、錄音演出。
*   **心得：** 結合角色背景（酒吧場景）進行分鏡設計，並學會利用鏡頭死角避開動作穿模問題。
